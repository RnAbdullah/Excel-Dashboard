# Adidas Sales Performance Dashboard

## 📌 Project Background
This project was developed following the Excel Bootcamp by King Khalid University in collaboration with the Professional Association for Statisticians & Data Scientists (PASDS).

It focuses on transforming raw retail data into meaningful insights through data analysis and visualization.

---

## 📊 Project Overview
An interactive Excel dashboard designed to analyze Adidas retail sales performance across regions, product categories, and sales channels.

The dashboard enables users to explore data dynamically using filters and uncover key business insights.

---

## 🛠️ Tools Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  

---

## 🔍 Analysis Process
- Cleaned and prepared the raw dataset  
- Used Pivot Tables to aggregate and summarize data  
- Created interactive charts and KPIs  
- Designed a dashboard with slicers for dynamic filtering

---

## 📈 Key Features
- Dynamic filtering by **Region, Product, and Sales Method**
- KPI cards for:
  - Total Sales (**899.9M**)
  - Average Operating Profit (**34.4K**)
  - Total Transactions (**9,648**)
- Time-series analysis of sales trends (2020–2021)
- Sales distribution by product category
- Sales channel performance (In-store, Online, Outlet)

---

## 💡 Key Insights
- Sales show a clear upward trend over time, especially in 2021  
- Men's Street Footwear generates the highest revenue among categories  
- In-store sales contribute the largest share compared to online and outlet
